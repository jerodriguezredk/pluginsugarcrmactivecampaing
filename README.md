# Plugin ActiveCampaign para SugarCRM

## Resumen Rápido / Quick Summary

### ¿Qué hace este plugin? / What does this plugin do?

**Español:** Sincroniza datos entre SugarCRM y ActiveCampaign, permitiendo gestionar contactos, cuentas y leads en ambas plataformas, además de rastrear estadísticas de campañas de email (enviados, abiertos, clics).

**English:** Synchronizes data between SugarCRM and ActiveCampaign, allowing management of contacts, accounts and leads in both platforms, plus tracking email campaign statistics (sent, opened, clicked).

### Dirección de Sincronización / Sync Direction

- **SugarCRM → ActiveCampaign:** Contacts, Accounts, Leads, Contracts (create/update/delete)
- **ActiveCampaign → SugarCRM:** Campaign statistics, Lead scores

### Requisitos / Requirements

- SugarCRM 9.x
- PHP 7.3
- ActiveCampaign account with API access
- Valid SugarActive Outfitters license
