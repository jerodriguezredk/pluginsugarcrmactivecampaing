#### Installation

You can install **Sugar-ActiveCampaign** via module loader from admin panel in sugarCRM.

#### Quickstart

Send Contacts, Accounts, Leads and TargetLists from sugarCRM to activeCmapaign kindly add the API keys in configuration setting page and then mappe the activeCampaign list from sugarCRM mosule and 
save the all settings.

After save the settings you will mapped the activeCampaign fileds with sugarCRM modules fields from mapping page.

if you want to sync existing Accounts, Contacts, Leads and Targetlist with activeCampaign then please create schdulers from sugarCRM scheduler module from admin panel.

Now you are completed all nessarry settings.

#### Create Campaign states in sugarCRM

When any campaign send to a contact from activeCampaign and user open click email then webhoook cal and states create in sugarCRM with sfecific contact, lead, account in sugarCRM in activeCampaign 
subpanel.

#### Deleting Record in SugarCRM

If any record will delete from sugarCRM or unlink from TargetList then automatically record will deleted or unlinked from a campain list in activeCmapaign
